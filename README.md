# Сорок — самопроверка хадисов

Готовый сайт находится в `dist/`. Добавлены все 40 разделов сборника имама аль-Аджурри.

- Арабский оригинал: последовательное открытие одной или двух строк, открыть всё, начать заново.
- Русский перевод Абу Аделя открывается отдельно.
- Выбор, поиск по номеру или теме, случайный хадис, предыдущий и следующий.
- На телефоне длинные строки переносятся между словами без распознавания или переписывания текста; счётчик соответствует строкам оригинала.
- Размер арабского текста регулируется кнопками А− / А+; увеличенную строку можно прокрутить горизонтально.
- Отметки повторения и настройки сохраняются в localStorage этого браузера.

## Запуск

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Сайт нужно открывать через HTTP, поскольку библиотека загружается из JSON.

## Источники и подготовка

В `dist/assets/` сохранены оба предоставленных PDF. 555 арабских строк представлены точными изображениями из оригинала: сохранены огласовки, иснады и дополнительные сообщения внутри раздела. Это не OCR. Нумерация карточек соответствует 40 разделам, а не внутренним номерам отдельных сообщений арабского издания.

`scripts/prepare_content.py` воспроизводит извлечение из двух исходных PDF в папке Downloads (нужны pypdfium2, pdfplumber, Pillow и numpy). Границы разделов сверены визуально. Текст перевода берётся до авторского разъяснения; полный контекст, примечания и оценки достоверности доступны через ссылки на русскую книгу.

Сайт предназначен для самостоятельной сверки: он не записывает голос и не оценивает произношение. Арабские строки являются изображениями, поэтому не копируются как текст.

## GitHub Pages

Публикация выполняется через `.github/workflows/pages.yml` из каталога `dist` при отправке изменений в `main`. В Settings → Pages выберите Source: GitHub Actions. Все локальные ресурсы используют относительные пути, поэтому сайт работает в подпапке репозитория.
