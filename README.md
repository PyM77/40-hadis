# Сорок — самопроверка хадисов

Сайт: https://pym77.github.io/40-hadis/. Готовая версия находится в `dist/`, включает все 40 разделов сборника имама аль-Аджурри.

- Арабский текст: открытие одной или двух строк, открыть всё, начать заново.
- Текст можно выделять, копировать и увеличивать. Локальный шрифт Amiri сохраняет чёткость букв и огласовок.
- Строки подстраиваются под ширину экрана и размер шрифта. Счётчик отражает строки на экране; их число может отличаться от печатной книги.
- При изменении размеров сохраняется граница открытых слов.
- Русский перевод Абу Аделя открывается отдельно; он взят из предоставленного PDF.
- Выбор, поиск по номеру или теме, случайный хадис, предыдущий и следующий.
- Отметки повторения и настройки сохраняются в localStorage этого браузера.

Сайт служит для самостоятельной сверки: он не записывает голос и не оценивает произношение.

## Запуск

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Библиотека загружается из JSON, поэтому нужен HTTP.

## Источники и редактирование

В `dist/assets/` сохранены оба предоставленных PDF. Арабский текст набран по арабскому изданию с помощью электронной версии для сверки; различия изданий исправлены по предоставленной книге. Сохранены иснады и дополнительные сообщения внутри разделов. Нумерация карточек соответствует 40 разделам, а не внутренним номерам отдельных сообщений. Ссылка на страницу PDF доступна в каждой карточке.

Редактируемый источник — `content/arabic-transcription.json`. Происхождение текста и принятые правила описаны в `content/arabic-source-review.md`, явные правки записаны в `content/arabic-editorial-changes.json`. После сверки изменений с PDF выполните:

```sh
python3 scripts/rebuild_text.py
python3 scripts/check_content.py
node --check dist/app.js
```

Сборка детерминирована и не использует OCR или нечёткое сопоставление. `scripts/fetch_shamela.py` сохраняет электронную версию только как вспомогательный материал. Черновик старого OCR-сопоставления находится в `scripts/archive/` и не подходит для сборки сайта.

`scripts/prepare_content.py` извлекает метаданные и перевод из двух исходных PDF в папке Downloads (нужны pypdfium2, pdfplumber, Pillow и numpy), затем повторно применяет проверенный арабский текст. Старые 555 изображений строк сохранены для сверки и истории, интерфейс их не использует.

Текст русского перевода берётся до авторского разъяснения. Полный контекст, примечания и оценки достоверности доступны в русской книге по ссылке. Арабский шрифт Amiri распространяется по SIL Open Font License; лицензия приложена в `dist/assets/fonts/`.

## GitHub Pages

`.github/workflows/pages.yml` проверяет содержимое и публикует `dist/` при отправке изменений в `main`. В Settings → Pages используется Source: GitHub Actions. Все локальные ресурсы имеют относительные пути, поэтому сайт работает в подпапке репозитория.
