# Сорок — самопроверка хадисов

Сайт: https://pym77.github.io/40-hadis/. Готовая версия находится в `dist/`, включает все 40 разделов сборника имама аль-Аджурри.

- Оформление из указанного пользователем образца: зелёная шапка, золотая рамка, орнаменты, узкая карточка и нижняя навигация.
- Режимы «Самопроверка» и «Чтение»: открытие одной или двух строк, открыть всё, начать заново.
- Текст можно выделять, копировать и увеличивать. Локальные шрифты Amiri и Inter взяты из того же Google Fonts, что и в образце. Сохранены исходные размеры, межстрочный интервал и выравнивание арабского текста.
- Строки подстраиваются под ширину экрана и размер шрифта. Счётчик отражает строки на экране; их число может отличаться от печатной книги.
- При изменении размеров сохраняется граница открытых слов.
- Русский перевод Абу Аделя открывается отдельно; он взят из предоставленного PDF.
- Выбор, поиск по номеру или теме, случайный хадис, предыдущий и следующий.
- Отметки повторения и настройки сохраняются в localStorage этого браузера.

Сайт служит для самостоятельной сверки: он не записывает голос и не оценивает произношение.

## Запуск

```sh
python3 -m http.server 4173 --directory dist
```

Откройте http://localhost:4173. Библиотека загружается из JSON, поэтому нужен HTTP.

## Сборка оформления

`python3 scripts/build_styles.py` собирает `dist/style.css` из сохранённых стилей образца и правил интерфейса в `styles/`. Установка npm-пакетов и внешний CDN для работы сайта не нужны. Происхождение дизайна и точные параметры шрифтов описаны в `content/design-reference.md`.

## Источники и редактирование

Арабский текст каждой карточки дословно взят из указанного пользователем сайта [40-hadiths-ajurri](https://github.com/cevekanovshoma-lab/40-hadiths-ajurri), включая сокращённые цепочки передатчиков, многоточия, огласовки и пунктуацию. Это отдельный выбор содержимого после переноса дизайна. Полный текст из PDF сохранён в `content/arabic-transcription.json` для истории, но больше не используется при сборке сайта.

Действующий источник — `content/arabic-reference.json`. Снимок оригинального HTML сохранён в `content/reference/index.html`; `scripts/import_reference_arabic.py` извлекает его арабские строки без запуска чужого JavaScript. Коммит и SHA-256 снимка записаны рядом с данными. После обновления снимка выполните `python3 scripts/import_reference_arabic.py`, затем:

```sh
python3 scripts/rebuild_text.py
python3 scripts/check_content.py
node --check dist/app.js
```

Сборка детерминирована; проверка требует посимвольного совпадения всех 40 текстов с HTML образца. Она не использует OCR, Unicode-нормализацию или нечёткое сопоставление. `scripts/fetch_shamela.py` сохраняет электронную версию только как вспомогательный материал. Черновик старого OCR-сопоставления находится в `scripts/archive/` и не подходит для сборки сайта.

`scripts/prepare_content.py` извлекает метаданные и перевод из двух исходных PDF в папке Downloads (нужны pypdfium2, pdfplumber, Pillow и numpy), затем повторно применяет арабский текст выбранного сайта. Старые 555 изображений строк сохранены для сверки и истории, интерфейс их не использует.

Текст русского перевода берётся до авторского разъяснения. Полный контекст, примечания и оценки достоверности доступны в русской книге по ссылке. Шрифты Amiri и Inter распространяются по SIL Open Font License; лицензия приложена в `dist/assets/fonts/`.

## GitHub Pages

`.github/workflows/pages.yml` проверяет содержимое и публикует `dist/` при отправке изменений в `main`. В Settings → Pages используется Source: GitHub Actions. Все локальные ресурсы имеют относительные пути, поэтому сайт работает в подпапке репозитория.
